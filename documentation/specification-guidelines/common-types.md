# Overview
This repo contains a set of shared common types for use by resource-management specs:

https://github.com/Azure/azure-rest-api-specs/tree/main/specification/common-types/resource-management

# Usage Guidelines
* Use the latest version containing **all** the types you need (likely `v5` or `v6` as of 2/28/2025).
* Never mix types from multiple versions (say `v5` **and** `v6`).
